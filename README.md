## How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/dhananjayshrama/backendlarning.git
   ```
2. Go into the folder
   ```bash
   cd backendlarning
   ```
3. Install packages
   ```bash
   npm install
   ```
4. Start the project
   ```bash
   npm start
   ```
